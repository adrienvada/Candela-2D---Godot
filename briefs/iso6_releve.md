## Pièges de harnais, relevés par ISO5 (à lire avant la première commande)

- Entrer dans le worktree par `EnterWorktree(path=…)` : sans lui, toute écriture y est refusée.
- Refusés par le harnais : `git -C <chemin>`, git dans une commande composée (`&&`, `;`, boucle), `HOME=…` même seul (les bancs tournent donc avec le foyer réel d'Adrien : `intro_vue=true`, et le banc passe en pilotage externe, rien n'est écrit), `perl -e 'alarm; exec'`, `bash script.sh`, une variable dans le chemin d'un programme ou d'un python, `${=var}`. Remèdes : commandes git simples, une par une ; chien de garde `Godot … & G=$!; (sleep 300; kill $G) & W=$!; wait $G` ; options de banc écrites en toutes lettres (sous zsh, une chaîne d'options dans une variable n'est pas découpée : quatre relevés ont mesuré la vue de dessus sous le nom de l'iso).
- `timeout` n'existe pas sur ce Mac. Une suite qui ne compile pas sort en code 0 : lire « SCRIPT ERROR|SHADER ERROR|Parse Error » au journal.
- Mac partagé (ISO Assets, Habillage, ISO7 Beauté, ISO7 Gadgets, ISO Corps peuvent lancer un lot) : attendre trois relevés `pgrep -x Godot` vides ; identifier un intrus par `ps -o pid,etime,command -p <pid>` puis `lsof -a -p <pid> -d cwd -Fn`, PID écrit en toutes lettres.

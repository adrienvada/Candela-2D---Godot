Le masque de la fumée et ses formes moins chères

Session cloud « masque-fumée », 27/09/2026. Torches éteintes, la fusée seule, caméra posée, LED figées : A sans fumée, puis la même fumée sans masque, avec le masque de Gadgets, avec chaque forme. Noir sali : en rouge, les pixels noirs sans fumée qu'elle allume ; en gris clair, le sol éclairé. Écart : en magenta, les pixels qui diffèrent du masque de Gadgets (au pied de J1, le corps frémit d'une prise à l'autre : deux prises de Gadgets y diffèrent autant). Rendu logiciel du cloud : vaut pour le noir et les comptes, pas pour la cadence.
